# Baguette Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une app macOS « baguette magique » : ouvrir une image, sélectionner par couleur, effacer en transparence, exporter en PNG.

**Architecture:** Swift Package à deux cibles. `WandCore` (bibliothèque, Foundation/CoreGraphics/ImageIO/Observation seulement, jamais AppKit ni SwiftUI) contient l'algorithme porté de photocraft, les opérations de masque, l'effacement, la lecture/écriture d'images et l'état d'édition `Editor` avec annulation — tout est testé par `swift test`. `Baguette` (exécutable SwiftUI + une `NSView` AppKit pour le canevas) n'est que de la présentation. `scripts/bundle.sh` assemble `Baguette.app`.

**Tech Stack:** Swift 6.4 (Command Line Tools, pas d'Xcode), SwiftPM, Swift Testing (`import Testing`), SwiftUI, AppKit, ImageIO, CoreGraphics.

**Spec:** `docs/superpowers/specs/2026-10-10-baguette-design.md`

**Référence de portage :** `crates/algo/src/selection.rs` de https://github.com/storytold/photocraft (fonctions `wand_region`, `antialias`, tests `wand_*`). Le lire avec
`gh api repos/storytold/photocraft/contents/crates/algo/src/selection.rs --jq .content | base64 -d`.

## Global Constraints

- Plateforme minimale : `.macOS(.v14)` ; `swift-tools-version: 6.0`.
- Aucune dépendance externe.
- `WandCore` n'importe jamais AppKit ni SwiftUI.
- Pixels : RGBA8 **non prémultipliés**, sRGB, origine en haut à gauche, rangée par rangée.
- Masque : `UInt8` par pixel, 0 = non sélectionné, 255 = sélectionné.
- Tolérance 0–255, défaut **32** ; Contigu défaut **oui** ; Lisser les bords défaut **oui** ; Contour progressif 0–50 px, défaut **0**.
- Fichiers portés de photocraft : en-tête `// Port de photocraft (storytold/photocraft, crates/algo/src/selection.rs), MIT OR Apache-2.0.` ; `NOTICE` le mentionne ; Baguette sous licence MIT.
- Textes d'interface en français, exactement ceux de la spec (« Glisse une image ici », « Ouvrir… », « Exporté », « Impossible d'ouvrir cette image », nom d'export `<nom>-baguette.png`).
- Commit (et `git push`) à la fin de chaque tâche ; messages en français, terminés par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Mettre à jour `NOTES.md` (section Décisions) quand une tâche prend une décision non écrite dans la spec.

## Review Focus

1. **Photos iPhone/appareil avec orientation EXIF** : l'image doit s'afficher et s'exporter dans le bon sens (sinon le clic tombe sur le mauvais pixel). → test dans Tâche 5.
2. **Images en niveaux de gris, 16 bits, CMJN ou avec profil P3** : doivent se charger et se convertir en RGBA8 sRGB sans échec. → test dans Tâche 5.
3. **Alpha prémultiplié de CoreGraphics** : un pixel semi-transparent doit garder sa couleur après chargement → export → rechargement (pas d'assombrissement). → test dans Tâche 5.
4. **Grandes images (photo 24 Mpx)** : un clic contigu sur un fond uni ne doit ni planter (pas de récursion) ni bloquer plusieurs secondes. → test dans Tâche 2.
5. **Correspondance clic → pixel avec zoom, Retina et défilement** : le pixel visé est celui sous le curseur, y compris aux bords. → test dans Tâche 7.

```swift
@MainActor @Observable public final class Editor {
  public private(set) var image: RGBAImage?
  public private(set) var selection: Mask?        // nil = rien de sélectionné
  public private(set) var isDirty: Bool             // modifié depuis chargement/export
  public var tolerance: Int = 32
  public var contiguous: Bool = true
  public var antiAlias: Bool = true
  public var featherRadius: Double = 0
  public var undoManager: UndoManager?
  public init()
  public func load(_ image: RGBAImage)              // remet sélection à nil, isDirty false, vide l'historique
  public func click(x: Int, y: Int, mode: SelectionMode)
  public func eraseSelection()                      // efface puis selection = nil
  public func invertSelection()                     // nil → tout sélectionné
  public func deselect()
  public func markExported()                        // isDirty = false
}
```

- [ ] **Step 1: Tests** (avec un `UndoManager()` réel, `groupsByEvent = false`, `beginUndoGrouping`/`endUndoGrouping` autour de chaque action dans le test ou dans `Editor`) :
  - `clickModes` : image 3×1 `[noir, blanc, noir]` tol 0, contigu, sans anticrénelage ni contour ; `click(0,0,.replace)` → `[255,0,0]` ; `click(2,0,.add)` → `[255,0,255]` ; `click(0,0,.subtract)` → `[0,0,255]` ; `click(2,0,.subtract)` → `selection == nil`.
  - `featherAppliedBeforeCombine` : avec `featherRadius = 2`, le masque après clic == `MaskOps.feather(MagicWand.select(...), radius: 2)`.
  - `eraseAndUndo` : sélection puis `eraseSelection()` → alpha 0 sur la zone, `selection == nil`, `isDirty == true` ; `undo()` → image et sélection d'origine ; `redo()` → effacé de nouveau.
  - `selectionUndo` : `click` puis `undo()` → `selection == nil`.
  - `invertWithoutSelection` : `invertSelection()` sans sélection → tout à 255.
  - `clickOutsideIsNoOp` : `click(x: 99, y: 0, …)` → aucun changement, rien à annuler.
  - `loadResets` : `load` → `selection == nil`, `isDirty == false`, `undoManager.canUndo == false`.
  - `markExported` remet `isDirty` à false ; une sélection seule ne rend pas `isDirty` vrai.
